# Лабораторная работа №5, вариант 12

Вариант: **NYSK** из UCI Machine Learning Repository.

Источник датасета: <https://archive.ics.uci.edu/dataset/260/nysk>

Датасет содержит 10421 англоязычную новостную статью в XML-формате. Так как у набора нет готовых истинных меток классов, качество кластеризации оценивается внутренними метриками:

- `silhouette_score` — чем больше, тем лучше;
- `calinski_harabasz_score` — чем больше, тем лучше;
- `davies_bouldin_score` — чем меньше, тем лучше.

При выборе итоговой модели скрипт дополнительно отбрасывает явно вырожденные разбиения: модели, где больше 75% документов попали в один кластер или больше 50% документов помечены как шум.

Скрипт выполняет пункты из [Lab05.md](Lab05.md):

1. скачивает UCI-архив, если он еще не лежит в `data/`;
2. парсит `nysk.xml`;
3. преобразует тексты в TF-IDF признаки;
4. снижает размерность через `TruncatedSVD`;
5. масштабирует признаки через `StandardScaler`;
6. проводит эксперименты с `KMeans`, `AgglomerativeClustering`, `Birch` и `DBSCAN`;
7. сохраняет результаты, графики и отчет в `outputs/`.

## Запуск

```bash
cd Lab05_variant12
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python lab05_variant12.py
```

По умолчанию используется равномерная подвыборка из `3000` документов, чтобы агломеративная кластеризация завершалась быстро. Для полного набора:

```bash
python lab05_variant12.py --max-docs 0
```

Файл `outputs/documents.csv` содержит промежуточную копию текстов корпуса, не включён в репозиторий и создаётся при запуске скрипта.
