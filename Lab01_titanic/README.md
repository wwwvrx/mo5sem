# Лабораторная работа №1. Анализ данных Titanic

Исходный набор данных: `titanic_train.csv`. Задания, решения и результаты находятся в ноутбуке.

## Запуск

```bash
cd Lab01_titanic
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook Lab01.ipynb
```

Выполните ячейки последовательно сверху вниз.
